# Student Expense Tracker System

## Overview

A Java command-line application that helps students manage and track their expenses.

## Features

- Add expenses
- Delete expenses
- View expenses
- Generate spending reports
- Save records to file
- Input validation

## Technologies Used

- Java
- OOP Concepts
- ArrayList
- Exception Handling
- File I/O

## Installation

1. Clone repository

```bash
git clone https://github.com/atraiu2007/Student-expense-tracker
```

2. Open project in IntelliJ IDEA

3. Compile:

```bash
javac *.java
```

4. Run:

```bash
java Main
```
