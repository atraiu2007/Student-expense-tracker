# Student Expense Tracker System

## Problem Statement

Students often struggle to keep track of daily expenses and spending habits. Manual tracking can be inaccurate and difficult to maintain.

## Scope

The system provides an easy way for students to:

- Add expenses
- Delete expenses
- View expense records
- Categorize spending
- Generate reports

## Target Users

- College students
- Hostel residents
- Budget-conscious individuals

## High-Level Features

1. Expense management
2. Category management
3. Report generation
4. File storage
5. Input validation
